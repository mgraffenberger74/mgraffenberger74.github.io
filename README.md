# mgraffenberger74.github.io

Öffentliche Seiten für die Apps von dmdumnot (GitHub Pages, Hauptverzeichnis – nötig für `app-ads.txt`).

- `index.html` – Startseite (in Google Play als Entwickler-Webseite eintragen)
- `mergeland/datenschutz.html` – Datenschutzerklärung „Mergeland Chronicles“ (in der Play Console eintragen)
- `impressum.html` – Impressum (§ 5 DDG)
- `app-ads.txt` – AdMob-Verkäuferangabe

Gelb markierte Platzhalter `[…]` vor der Veröffentlichung ersetzen.
